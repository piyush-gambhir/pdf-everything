## Reproduce

Install the repository's locked dependencies using its package manager, then run from each application directory on Next.js 16.4 or later:

```bash
pnpm run bundle:analyze --snapshot audit-before-unique
bash -o pipefail -c 'pnpm --silent run bundle:export --snapshot audit-before-unique | gzip > /tmp/bundle-before.jsonl.gz'
```

Use `npm run bundle:analyze -- --snapshot audit-before-unique` for npm projects. For npm export, use `npm run --silent bundle:export -- --snapshot audit-before-unique` so npm command banners do not enter JSON stdout. If there is a custom `distDir`, pass the matching `--dist-dir` to export. Use distinct snapshot and export names for before/after captures. Export requires Next.js 16.4 or later; older projects use `pnpm run bundle:analyze` without `--snapshot`, invoking their installed `experimental-analyze` command. They only receive the export command after upgrading.

For future fixes, inspect actual importers and render conditions, change one boundary, compare the same routes/output class/metric, and exercise the first interaction with the deferred feature. Use browser measurements to substantiate runtime or transfer improvements.
