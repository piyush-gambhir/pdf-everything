**pdf-everything** is a set of PDF tools that runs both as a browser console and as
a REST API. The console is not a special client — it calls exactly the same
endpoints any external caller would.

## The pieces

| Piece               | What it is                                                         |
| ------------------- | ------------------------------------------------------------------ |
| **Console**         | The statically deployed Next.js UI for every tool.                 |
| **Nest API**        | The public REST contract used by the console and external clients. |
| **PDF core worker** | Executes the 17 existing PDF, image, text, and form operations.    |
| **Browser worker**  | Executes HTML → PDF and Markdown → PDF through Chromium.           |
