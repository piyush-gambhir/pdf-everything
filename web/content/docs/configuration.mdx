## Static web and docs

The web app is a static export mounted at `/pdf-everything`.

| Variable                     | Required | Purpose                                                                        |
| ---------------------------- | -------- | ------------------------------------------------------------------------------ |
| `NEXT_PUBLIC_CONSOLE_ORIGIN` | no       | Separate console origin; local development defaults to `http://localhost:3000` |

In production, omit the variable when the site and console share the same
origin and are routed by path.

## Console

The console is a static export mounted at `/pdf-everything/console`.

| Variable                  | Required   | Default                                                    | Purpose                 |
| ------------------------- | ---------- | ---------------------------------------------------------- | ----------------------- |
| `NEXT_PUBLIC_API_ORIGIN`  | production | `http://localhost:3001`                                    | Public Nest API origin  |
| `NEXT_PUBLIC_SITE_ORIGIN` | no         | local web server in development; same origin in production | Website and docs origin |

These values are compiled into the static JavaScript bundle. Rebuild the
console after changing them.

## Nest API

| Variable                       | Default                 | Purpose                                                 |
| ------------------------------ | ----------------------- | ------------------------------------------------------- |
| `API_PORT`                     | `3001`                  | Public HTTP port                                        |
| `STORAGE_DIR`                  | `./storage`             | Temporary local file directory                          |
| `FILE_TTL_HOURS`               | `24`                    | Stored-file lifetime                                    |
| `PDF_CORE_WORKER_URL`          | `http://127.0.0.1:8020` | Core worker origin                                      |
| `PDF_CORE_WORKER_TOKEN`        | unset                   | Bearer token sent to the core worker                    |
| `PDF_RENDER_WORKER_URL`        | `http://127.0.0.1:8010` | Chromium worker origin                                  |
| `PDF_RENDER_WORKER_TOKEN`      | unset                   | Bearer token sent to the Chromium worker                |
| `MAX_UPLOAD_MB`                | `100`                   | Largest multipart request, and each file or field in it |
| `PDF_CORE_WORKER_TIMEOUT_MS`   | `120000`                | Deadline for a core worker exchange (then `504`)        |
| `PDF_RENDER_WORKER_TIMEOUT_MS` | `60000`                 | Deadline for a render worker exchange (then `504`)      |

Uploads are held in memory until a worker answers. A multipart request larger
than `MAX_UPLOAD_MB` is refused with `413` before it is read, and one that does
not declare its `Content-Length` with `411`. The render routes accept no files.

`FILE_TTL_HOURS` must be positive. Expired files stop being accessible immediately;
the API removes expired references and unreferenced content at startup and every
minute while running.

The current file store is local filesystem storage. A horizontally scaled Nest
deployment needs shared object storage or sticky routing; otherwise one replica
cannot read a file created by another replica.

## PDF core worker

| Variable                | Default     | Purpose                                        |
| ----------------------- | ----------- | ---------------------------------------------- |
| `PORT`                  | `8020`      | Worker HTTP port                               |
| `WORKER_API_TOKEN`      | unset       | Bearer token required on execution routes      |
| `MAX_REQUEST_BYTES`     | `157286400` | Maximum internal JSON request body             |
| `MAX_ACTIVE_OPERATIONS` | `2`         | Operations at once; more get `503 worker_busy` |

`WORKER_API_TOKEN` must match `PDF_CORE_WORKER_TOKEN` on Nest.

## Chromium worker

| Variable                    | Default       | Purpose                                         |
| --------------------------- | ------------- | ----------------------------------------------- |
| `PORT`                      | `8010`        | Worker HTTP port                                |
| `API_TOKEN`                 | unset         | Bearer token required on render routes          |
| `MAX_REQUEST_BYTES`         | `5242880`     | Maximum JSON body                               |
| `MAX_ACTIVE_RENDERS`        | `4`           | Renders at once; more get `503 worker_busy`     |
| `RENDER_TIMING_LOG`         | on            | One JSON timing line per render; `off` stops it |
| `PUPPETEER_EXECUTABLE_PATH` | auto-detected | Chromium executable                             |

`API_TOKEN` must match `PDF_RENDER_WORKER_TOKEN` on Nest.

## Secret handling

- Keep worker tokens in the target platform's secret manager.
- Never include worker tokens in `NEXT_PUBLIC_*` variables.
- Never expose private worker URLs to the console.
- Use long, independently generated values for the two worker groups.
- Rotate a worker token by updating the worker first, then Nest during a
  controlled rollout.
